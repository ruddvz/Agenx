### 6. Error Messages and Empty States

**Rules for error messages:**
1. Say what happened in plain language
2. Say what the user can do right now
3. Give the actual contact, not a promise of support

**Before:**
> Oops! Something went wrong. We apologise for the inconvenience. Please try again later.

**After:**
> [Product-specific clear error message with action]

**Rules for empty states:**
- Tell the user why it is empty
- Tell them what action fills it
- Do not be cute about it

**Before:**
> You haven't [done X] yet. Start your journey today!

**After:**
> No [X] yet. [Specific action to fill it].
